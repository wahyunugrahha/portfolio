# Wahyu Nugraha - Personal Portfolio 🚀

A modern, fast, and fully responsive personal portfolio website showcasing my projects, skills, and certifications. Built with **Nuxt 3** and **Tailwind CSS**.

## ✨ Features

- 🌓 **Dark Mode / Light Mode**: Seamless theme toggling with persistent user preference (Local Storage).
- 🌍 **Bilingual Support (ID/EN)**: Instantly switch the website's language between English and Indonesian without page reloads.
- 💫 **Smooth Animations**: Staggered fade-in-up animations on load, typewriter text effects, and smooth hover transitions.
- 📱 **Fully Responsive**: Beautifully crafted for all screen sizes, from mobile phones to large desktop monitors.
- ⚡ **Performant**: Powered by Nuxt 3 (Vue 3) and Vite for blazing-fast load times.

## 🛠️ Tech Stack

- **Framework**: [Nuxt 3](https://nuxt.com/) (Vue.js)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State Management**: Vue Composition API (Refs & Composables)
- **Icons**: Heroicons (SVG)

## 🚀 Setup & Installation

Follow these steps to run the project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/wahyunugrahha/nama-repo-anda.git
   cd portfolio
   ```

2. **Install dependencies**
   Make sure you have [Node.js](https://nodejs.org/) installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   *The application will be running at `http://localhost:3000`*

## 📦 Build for Production

To build the application for production deployment:

```bash
npm run build
```

You can then preview the production build locally:

```bash
npm run preview
```
